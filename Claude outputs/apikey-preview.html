Connect Claude

Step 1 of 3

Open the Claude Console and sign in

New account? Add a few dollars of credits under Billing first.

Open Claude Console

Step 2 of 3

Create a key and copy it

In the Console, go to API keys, click Create key, and give it any name.

Step 3 of 3

Paste your key

Your key stays in your browser.

Need help? Log out
  • A Claude Pro or Max subscription doesn't include API access. The API is billed separately with Console credits.
  • Your key starts with sk-ant-. The Console only shows it once, so copy it in one go.
  • Lost it? Create a new key and paste that one instead.
  • On a shared computer, log out when you're done.
