Write a function that returns the largest number in an array.

Your code 
function findLargest(numbers) {
  if (numbers.length === 0) {
    throw new Error("The array is empty");
  }
  let largest = numbers[0];
  for (const n of numbers) {
    if (n > largest) {
      largest = n;
    }
  }
  return largest;
}
Reference solution 
function findLargestNumber(numbers) {
  // An empty array has no largest value
  if (numbers.length === 0) {
    throw new Error("Cannot find the largest number of an empty array.");
  }

  // Start with the first item so negative numbers work
  let largest = numbers[0];

  // Check every remaining item
  for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
      largest = numbers[i];
    }
  }

  return largest;
}

How they compare

Your code does the same job as the reference: it throws an error for an empty array, starts largest at numbers[0], and replaces it whenever it finds something bigger. Your for...of loop also looks at the first item again, which is harmless, while the reference starts at index 1. Both are valid.

The idea behind the reference

Keep a running champion: take the first item as the biggest so far, then swap it only when something larger shows up. A shorter alternative is Math.max(...numbers), but writing the loop yourself shows how the answer is found.
